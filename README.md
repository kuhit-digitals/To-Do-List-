# 📝 Todo List App

A simple and classy Todo List web application built as a learning project while exploring web development fundamentals.

---

## 🚀 About The Project

This project was built as part of my learning journey in web development. It took me around **6 hours and 10 minutes** to complete using **VS Code**.

I built this project independently while still being in the learning stage, focusing on improving my understanding of frontend development and basic project structuring.

---

## 🛠️ Built With

- HTML
- CSS
- JavaScript

---

## ✨ Features

- Add new tasks
- Delete tasks
- Clean and simple UI
- Smooth and classy visual effects
- Beginner-friendly structure

---

## 🧠 What I Learned

- DOM manipulation using JavaScript  
- Structuring a complete small web project  
- Styling with CSS for better UI experience  
- Debugging and fixing issues during development  
- Improving logic-building skills step by step  

---

## ⏱️ Project Stats

- **Time Taken:** 6 Hours 10 Minutes  
- **Environment:** VS Code  
- **Level:** Beginner Project  

---

## ⚙️ Challenges Faced

While building the backend logic (JavaScript functionality), I faced a few bugs and issues. Some of them were solved with the help of AI assistance, which helped me understand better ways to debug and improve my code.
